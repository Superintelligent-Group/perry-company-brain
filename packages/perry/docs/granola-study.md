# Granola Study And Perry Product Direction

Generated: 2026-05-23

## Current Granola Read

Granola is excellent at low-friction personal capture:

- It is not a meeting bot. It runs from the user's device and captures system audio plus microphone audio.
- It starts transcription only after user action or when an opened scheduled note reaches meeting time.
- It produces AI-enhanced notes from transcript, raw user notes, and calendar context.
- It supports templates, profile context, folders/spaces, search, Slack, Notion, Zapier, CRM integrations, MCP, and API access on higher plans.
- Desktop real-time transcription does not currently provide full live diarization.
- Native Notion sharing is useful but not enough for company-brain automation by itself.

## Perry Should Not Copy Granola

Perry's product surface should begin where Granola's note-taking surface ends:

1. Capture from Granola, Discord, Notion, manual notes, and future audio/transcript sources.
2. Normalize every source into one company-brain object model.
3. Extract decisions, action items, owners, projects, open questions, source links, and follow-ups.
4. Let humans preview and approve before noisy posts.
5. Route the right summary to the right Discord channel/thread.
6. Write durable, structured pages and records to Notion.
7. Make everything source-cited and retrievable later.

## Real-Time Without Being Annoying

The right model is progressive disclosure:

- During meetings: do not interrupt unless explicitly invited.
- Immediately after meetings: create a draft and quiet preview.
- When confidence is high: post a concise Discord summary with links.
- When confidence is low: ask for approval.
- For follow-up: only ping owners for clear action items, not every attendee.
- For backfills/replays: never post duplicates.

## Product Bar

Perry should be judged against these capabilities:

- Idempotent ingestion.
- Source preservation.
- Structured extraction.
- Human approval controls.
- Cross-tool identity graph.
- Search with citations.
- Project/channel routing.
- Action item ownership.
- Audit log.
- Admin diagnostics.
- Backfill and retry.

Granola remains a strong capture source. Perry becomes the company operating memory.
